## The Challenge: Webhook Contract Drift & Unchecked Payloads

Modern web applications integrate with external webhook providers (such as Stripe, GitHub, Shopify, or Svix). While providers publish JSON Schemas or documentation, breaking changes or unexpected optional fields frequently cause runtime `TypeError: Cannot read properties of undefined` in production event handlers.

Using TypeScript interfaces alone (`as StripeWebhookPayload`) provides **zero runtime validation**. If the upstream payload shape drifts, TypeScript casts the invalid object into memory unchecked.

## Complete Downstream Implementation (Next.js / Node.js API Route)

Below is an idiomatic downstream implementation showing how to safely verify the webhook's cryptographic signature, validate the raw body against the generated Zod schema, and process the typed event:

```typescript
import { NextRequest, NextResponse } from "next/server";
import crypto from "node:crypto";
import { z } from "zod";

// ============================================================================
// 1. Zod Schema & Inferred Type (Generated by Toolbox)
// ============================================================================
export const WebhookEventSchema = z.object({
  id: z.string().uuid(),
  event: z.enum(["payment.succeeded", "payment.failed", "customer.subscription.deleted"]),
  timestamp: z.number().int().positive(),
  data: z.object({
    order_id: z.string().min(1),
    amount_cents: z.number().int().nonnegative(),
    currency: z.string().length(3).default("USD"),
    customer_email: z.string().email(),
    metadata: z.record(z.string(), z.string()).optional(),
  }),
});

export type WebhookEvent = z.infer<typeof WebhookEventSchema>;

// ============================================================================
// 2. Cryptographic Signature Verification
// ============================================================================
function verifyWebhookSignature(
  rawBody: string,
  signatureHeader: string | null,
  secret: string
): boolean {
  if (!signatureHeader) return false;

  const expectedSignature = crypto
    .createHmac("sha256", secret)
    .update(rawBody)
    .digest("hex");

  // Constant-time comparison to prevent timing attacks
  const expectedBuffer = Buffer.from(expectedSignature, "utf8");
  const providedBuffer = Buffer.from(signatureHeader, "utf8");

  if (expectedBuffer.length !== providedBuffer.length) return false;
  return crypto.timingSafeEqual(expectedBuffer, providedBuffer);
}

// ============================================================================
// 3. Next.js App Router POST Handler
// ============================================================================
export async function POST(req: NextRequest) {
  const webhookSecret = process.env.WEBHOOK_SIGNING_SECRET;
  if (!webhookSecret) {
    return NextResponse.json(
      { error: "Server misconfiguration: missing webhook secret" },
      { status: 500 }
    );
  }

  // Read raw text to preserve exact bytes for HMAC calculation
  const rawBody = await req.text();
  const signature = req.headers.get("x-signature-sha256");

  // Step 1: Verify authenticity
  const isValid = verifyWebhookSignature(rawBody, signature, webhookSecret);
  if (!isValid) {
    return NextResponse.json(
      { error: "Invalid signature verification" },
      { status: 401 }
    );
  }

  // Step 2: Parse JSON
  let unvalidatedJson: unknown;
  try {
    unvalidatedJson = JSON.parse(rawBody);
  } catch {
    return NextResponse.json(
      { error: "Malformed JSON payload" },
      { status: 400 }
    );
  }

  // Step 3: Validate against Zod schema (Guarantees zero contract drift)
  const parseResult = WebhookEventSchema.safeParse(unvalidatedJson);
  if (!parseResult.success) {
    console.error("Webhook schema drift detected:", parseResult.error.format());
    return NextResponse.json(
      {
        error: "Contract validation failed",
        details: parseResult.error.errors,
      },
      { status: 422 }
    );
  }

  // Step 4: Safely consume strongly-typed payload
  const event: WebhookEvent = parseResult.data;
  console.log(`Processing valid event: ${event.event} for order ${event.data.order_id}`);

  // Business logic here...

  return NextResponse.json({ received: true, eventId: event.id });
}
```

## Benefits of This Pattern

1. **Deterministic Edge Safety**: Invalid or structurally mutated events are rejected with HTTP 422 before reaching core domain models.
2. **Zero Runtime Exceptions**: Fully typed access (`event.data.amount_cents`) is guaranteed to exist and match expectations.
3. **Air-Gapped Generation**: The Zod schema can be created using [Toolbox](https://toolbox.vishnudigital.com/json-schema-to-typescript) without uploading internal company schemas to third-party cloud servers.
